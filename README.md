# J.A.R.V.I.S.

**Just A Rather Very Intelligent System**  
Assistente personale vocale ispirato a JARVIS di Iron Man.

## Demo live

Apri il file `index.html` in un browser moderno (Chrome consigliato) oppure attiva **GitHub Pages**.

## Funzionalità attuali

- Interfaccia olografica dark theme con animazioni
- **Sintesi vocale** in italiano (Jarvis parla)
- **Riconoscimento vocale** in italiano (puoi parlare)
- Comandi base: saluti, ora, data, presentazione, ecc.
- Input testuale di backup

## Come usarlo

1. Apri `index.html` in Chrome / Edge / Safari
2. Autorizza il microfono quando richiesto
3. Tocca il pulsante microfono e parla, oppure scrivi nel campo di testo
